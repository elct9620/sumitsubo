# Prose

What a file no language claimed answers with.

Prose is a comment for its whole length, so the file answers entire and nothing
has to be found in it. It answers to no name and declares nothing: a
specification asking what a file declares has already said which language it
means, and prose is what a file falls to rather than something named.

That leaves it one question of the four a language answers — what each region
stands next to — and the reading needs no grammar to answer it. It is the one
reading a build carries whose test can be regenerated.
